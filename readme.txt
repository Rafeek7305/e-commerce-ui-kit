A premium Elementor extension providing infinite collection slider and featured cards.

== Description ==
Handzom UI Kit is a premium extension for Elementor developed by Azasoft Solutions. 
It adds modern, highly customizable widgets to your Elementor panel.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/handzom-ui-kit` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Edit any page with Elementor and look for the "Handzom UI Kit" category in the widgets panel.
